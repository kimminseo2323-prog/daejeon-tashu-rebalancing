# 샘플 데이터 안내

모두 numpy seed 42 난수로 만든 **합성 데이터**이며 실제 타슈 이용 기록과 무관하다.

## `rental_events_sample.csv` (200행)
`01_preprocess.py`가 `대전시 공영자전거 타슈 대여이력 정보*.csv`를 병합해 만드는 `bike_rental_data`의 컬럼을 따른다.

| 컬럼 | 설명 |
|---|---|
| `대여일시`, `반납일시` | `YYYY-MM-DD HH:MM:SS`. 스크립트가 공백 기준으로 일자/시간으로 분리 |
| `자전거번호` | 자전거 식별자 |
| `대여_대여소ID`, `대여_대여소명`, `대여_대여소주소`, `대여_구`, `대여_동` | 대여 대여소 정보 (구·동 결측 시 주소에서 보완하는 로직의 입력) |
| `반납_대여소ID`, `반납_대여소명`, `반납_대여소주소`, `반납_구`, `반납_동` | 반납 대여소 정보 |
| `이용시간(분)`, `이용거리(km)` | 현황분석(`04_status_analysis.py`)에서 사용 |

## `stations_sample.csv` (20행)
`타슈 대여소 내역.csv`(`station_locations`) 대응. `대여소ID, 대여소명, 구, 동, 주소, 위도, 경도` — `06_clustering.py`의 좌표 Min-Max 스케일링·K-Means 입력에 해당.
